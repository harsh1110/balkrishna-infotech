# Balkrishna Infotech

Marketing site for Balkrishna Infotech — a product engineering studio for web, mobile, SaaS, eCommerce, AI and digital growth.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand source

Implementation follows the Brand, UI/UX, Product, SEO & Performance specification: dark charcoal foundations, blue→cyan gradient accents, Sora display + Inter body, and the homepage information architecture from positioning through conversion.
