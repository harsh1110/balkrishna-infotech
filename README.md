# Balkrishna Infotech

Marketing site for Balkrishna Infotech — a product engineering studio for web, mobile, SaaS, eCommerce, AI and digital growth.

## Live site (GitHub Pages)

**https://harsh1110.github.io/balkrishna-infotech/**

Enable once in repo settings if the URL 404s: **Settings → Pages → Deploy from a branch → `gh-pages` / root → Save**.

## Stack

- Next.js (App Router, static export)
- TypeScript
- Tailwind CSS
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## GitHub Pages build

```bash
npm run build:pages
# preview locally:
mkdir -p /tmp/pages-root/balkrishna-infotech && cp -a out/. /tmp/pages-root/balkrishna-infotech/
npx serve /tmp/pages-root
```

Light theme with the official monogram, charcoal/graphite neutrals, blue→cyan accents, Sora display + Inter body, and the homepage IA from the product specification.
